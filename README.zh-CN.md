# Codex 本地项目迁移

[English](README.md)

把指定的 **Codex 本地项目、原会话、截图和附件** 从旧 Mac 迁到新 Mac。技能会帮助你逐项确认文件是否齐全、原会话是否能读，以及能否在新 Mac 的对应项目侧栏中继续聊天。

这是社区技能，首版面向 Mac 到 Mac 的 Codex 桌面版迁移。随附的 Python 工具负责只读导出和校验。正式写入新机前，需要在隔离副本里验证当前版本能否正确读取会话并归组。

## 安装

**完整迁移建议新旧两台 Mac 都安装。** 这样两边的 Codex 都能按同一套指引处理本机的文件和会话。在每台 Mac 上，把整个 [`skills/codex-local-migration`](skills/codex-local-migration) 文件夹复制到 `~/.agents/skills/`。如果只想在某个项目里使用，可以复制到该项目的 `.agents/skills/`。然后打开新的 Codex 会话。运行导出工具需要 Python 3.9 或更新版本。导出 `.jsonl.zst` 压缩日志还需要可信的 `zstd` 可执行文件。 [OpenAI 技能安装说明](https://developers.openai.com/api/reference/cli)

## 将 Codex 本地项目和会话迁移到新 Mac

### 在旧 Mac 上导出

1. **生成迁移包。** 安装 `codex-local-migration` skill，在 Codex 里说明要迁移的项目和会话，请它生成迁移包。
2. **发送到新 Mac。** 用 AirDrop 传送迁移包。在新 Mac 的「下载」中找到收到的文件。如果收到的是压缩包，先解压。把解压后的整个文件夹移到长期使用的位置，例如 `~/Documents/Codex/Codex 迁移/`。

### 在新 Mac 上恢复

3. **在侧栏添加本地项目。** 在 Codex 侧栏选择「项目 → ＋ → 本地」，使用原项目的名称。选择迁移包内实际存放项目文件的目录作为主目录。
4. **单独开一个会话执行迁移。** 在刚添加的项目之外，新建一个独立的 Codex 会话。在这个会话里安装 `codex-local-migration` skill，然后直接告诉 Codex 项目名称，请它恢复该项目的会话。
5. **按提示核对项目路径。** 如果 Codex 提示你手动修改路径，在侧栏编辑该项目，把主目录指向第 3 步选定的项目文件夹。
6. **等 Codex 提示后再完全退出。** Codex 确认导入程序已就绪后，按 `⌘Q`，也可以右键点击程序坞里的应用图标并选择「退出」。如果 Codex 提示本次迁移会自动重开，等它自行打开。如果提示需要手动重开，等导入程序显示「导入完成」后再打开。
7. **检查迁移结果。** 从新 Mac 的项目侧栏打开恢复的原会话，确认旧消息和需要的附件可读。如果希望继续之前的工作，可以接着问一个只有旧会话里才有的细节。

## 只迁一次，直接使用解压包

在需要执行步骤的 Mac 上下载并解压仓库 ZIP，保留完整的 Skill 文件夹。打开一个本地 Codex 对话，附上解压后的 `skills/codex-local-migration/SKILL.md`，或发给 Codex 它在本机的完整路径。让它读完后按上面的「在旧 Mac 上导出」或「在新 Mac 上恢复」步骤执行。旧机告诉它要迁哪些项目和会话，新机直接告诉它项目名称。如果旧 Mac 已经导出完成，只需要在新 Mac 解压并使用 Skill。

## 包含哪些步骤

校验和隔离测试可以先做。正式归入原会话前，确认侧栏项目的主文件夹已指向长期存放的内层目录。

- **旧机导出。** 按项目整理文件、会话和媒体，保留原生日志及对应的数据库记录。
- **传输和接收。** 用隔空投送或其他私下传输方式发送，接收后核验 SHA-256。
- **处理同 ID 多份日志。** 同时保留候选日志，核对历史数据库的字节偏移和真实对话轮次，再在隔离环境选定恢复版本。
- **新机验收。** 分别确认项目文件、原会话身份、可读历史和图片、侧栏分组，以及实际续聊。

主入口和详细步骤见 [SKILL.md](skills/codex-local-migration/SKILL.md)。原生迁移包可能含私人对话和工具结果，请存放在仓库外。公开仓库适合上传技能源码和合成测试。

在仓库根目录执行下面的命令可运行测试：

```sh
python3 -B -m unittest discover -s tests
```

也可用已安装的 Codex CLI 跑一次隔离集成测试：

```sh
python3 -B tests/verify_app_server.py
```

已在 `codex-cli 0.171.0-alpha.13` 上通过。测试使用两套临时数据目录，检查同 ID 日志冲突、内嵌用户和工具图片、原会话 ID、新工作目录、项目归属，以及重启后能否读回两条会话。桌面侧栏和实际续聊需要在目标 Mac 单独验收。该测试依赖本机 CLI 提供相应的实验性恢复和项目接口。
